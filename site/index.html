      Downloaded it? Verify it.

      Every release includes SHA256SUMS. Thirty seconds of verification are worthwhile: a tampered client is the last thing you want handling your traffic.

      Linux and macOS

      sha256sum -c SHA256SUMS --ignore-missing

      Windows (PowerShell)

      Get-FileHash .\Skyward-<version>-windows-amd64-setup.exe -Algorithm SHA256

      Build it yourself without waiting for a release.

      A direct way to trust your client: see what you build.

        Build

        git clone --recurse-submodules https://github.com/aqiyoung/Skyward.git
cd Skyward
flutter pub get
dart run setup.dart            # host platform
dart run setup.dart android    # APK
# → dist/

        Windows needs the Visual Studio C++ toolchain; macOS needs Xcode. The desktop executable is named SkywardCore.
