What Skyward does for you.

A multi-platform client on the mihomo core: the things you would otherwise dig for are on the screen.

  • Kernel-level routing

    Rules, strategy groups, GeoIP and fake-ip from mihomo. One subscription link and every platform routes the same way.

  • Traffic and time, always in sight

    Remaining data and the period end stay on the main screen, with a history of usage and rankings you can actually read.

  • A route map, not a server list

    See where traffic leaves: a globe you can switch to a flat map, with the exit and the path drawn out.

  • Split routing that holds

    Send chosen apps or sites through the exit you pick — or nowhere — whatever the mode or the rest of the rules say.

  • Numbers when you want them

    Live connections, DNS queries and logs, plus the memory the core actually uses — no more guessing what it is doing.

  • One client, four platforms

    Windows, macOS, Linux and Android share the same profiles, the same groups and the same settings.

One link and three steps.

Bring your own subscription. No account, no registration, no email.

  1. 1

    Install the client

    Windows, macOS, Linux or Android — installer or portable build, whichever suits you.

  2. 2

    Add your subscription

    Paste the link or import the configuration file. Clash/mihomo profiles and common node links both work.

  3. 3

    Connect

    Pick a profile and a node, then start it. Android asks for the VPN permission; desktop TUN needs the system helper.

Already have a link?

Download the client, paste the link into it and the profile appears — no account and nothing to configure by hand.

    Which package for which system.

    Every release ships the same four platforms.

      Downloaded it? Verify it.

      Every release includes SHA256SUMS. Thirty seconds of verification are worthwhile: a tampered client is the last thing you want handling your traffic.

      Linux and macOS

      sha256sum -c SHA256SUMS --ignore-missing

      Windows (PowerShell)

      Get-FileHash .\Skyward-<version>-windows-amd64-setup.exe -Algorithm SHA256

      Build it yourself without waiting for a release.

      A direct way to trust your client: see what you build.

        Build

        git clone --recurse-submodules https://github.com/aqiyoung/Skyward.git
cd Skyward
flutter pub get
dart run setup.dart            # host platform
dart run setup.dart android    # APK
# → dist/

        Windows needs the Visual Studio C++ toolchain; macOS needs Xcode. The desktop executable is named SkywardCore.
